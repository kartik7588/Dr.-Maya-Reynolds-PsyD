# Dr. Maya Reynolds — Therapy Homepage

A responsive Next.js and Tailwind CSS homepage created for the Grow My Therapy Stage 2 front-end assignment.

## Run locally

```bash
npm install
npm run dev
```

Open `http://localhost:3000`.

## Assignment coverage

- Preserves the source homepage’s editorial flow and responsive hierarchy.
- Replaces all copy with content grounded in Dr. Maya Reynolds’ supplied profile.
- Uses a new Santa Monica–inspired color and typography system.
- Includes three profile-derived services: anxiety and panic, trauma therapy, and burnout/perfectionism.
- Uses the supplied portrait and office photography.
- Adds an original “Our Office” section with the supplied location and session formats.
- Includes local SEO metadata, semantic structure, keyboard navigation, reduced-motion support, and responsive layouts.

## Important submission note

No verified contact address or booking URL was supplied, so the page does not fabricate one. The consultation area clearly identifies where the final verified contact method should be connected before publication.

## Deploy

Import this repository into Vercel and use the default Next.js settings. No environment variables are required.
